# Design system
Mood: dreamy night sky (cover) + bold flat sticker cards (collectibles) + NASA telemetry details (Space Mono labels, red/blue accents).
Fonts: Archivo Black (headings, card names), Nunito (text), Space Mono (data labels), Caveat Brush (cover title), Lilita One (chapter covers).
Colors: see `src/styles/tokens.css`. NASA blue `#0b3d91`, NASA red `#fc3d21`, gold `#ffd34e`, ink `#14122b`.
Rules: 3.5px dark outlines, 22px radius, flat colors with a hard offset shadow, big tap targets (44px+), never rely on color alone.
Do not use the official NASA logo; the patch-style icon in the top bar is our own.
