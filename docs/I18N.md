# Translations (i18n)
Owner: P3 (loader + en.json). Translators: P1 (bn.json, ar.json).

**Files**: `src/i18n/locales/en.json` (source), `bn.json`, `ar.json` (same keys, translated). Flat JSON: `"key": "text"`.
**Rules**: keep the keys exactly as in en.json, translate only the value. Keep `{placeholders}` like `{n}` or `{rank}` unchanged. Age 8 to 12 reading level. A key you leave out simply shows English.
**Add a language**: create `locales/<code>.json`, set `enabled:true` in `src/i18n/languages.js` (Arabic is already listed, right-to-left is automatic).

## Key groups in en.json
| Prefix | What it is |
|---|---|
| `nav.*`, `topbar.*`, `common.*`, `rank.*`, `unit.*` | menu, buttons, ranks, km/time words |
| `hub.*`, `map.*`, `world.*`, `chapter.*`, `mission.*`, `quiz.*`, `play.*`, `lander.*`, `memory.*`, `timeline.*`, `album.*`, `landing.*`, `credit.*`, `card.*`, `modal.*` | one group per screen |
| `intro.N` | the Pip intro lines on the cover |
| `robot.<NAME>.tagline`, `.story.N.title`, `.story.N.text`, `.quiz.q/right/wrong1/wrong2` | robot content (from `src/data/missions.js`) |
| `quiz.N.q`, `quiz.N.o0..o3`, `quiz.N.e` | quiz bank (N = position in `src/data/quiz.js`; o0 is the RIGHT answer) |
| `badge.<id>.name/desc`, `body.<id>.name/fact/km` | patches and planets |

| `tour.*`, `state.*`, `status.*`, `filter.*`, `sources.*`, `lastMessage.*`, `live.*`, `whyLeft.*`, `buggy.*`, `map.credit*`, `cert.*`, `toast.*` | shared components and newer screens |
| `ww.*` | the Web Walker quiz game. `ww.q.<id>.question`, `.o0`-`.o3`, `.fact` are its 35 questions. Bangla for the UI keys already exists in `src/games/WebWalkerQuiz/i18n/bn.ww.json`, ready to merge |

Text that lives in data files (Last Message lines, Why-we-left sections, data sources) is translated with `lastMessage.<robotId>.<lineId>`, `whyLeft.<sectionId>.title|text`, `source.<datasetId>.usedFor`.

Facts such as dates and places inside `src/data/relics.json` are not translated yet (shown in English).
If P1 re-orders `quiz.js`, move the `quiz.N.*` keys too, or add an `id` to each question.
